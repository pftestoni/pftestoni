### Featured project
**[rl-coil-cutting](https://github.com/pftestoni/rl-coil-cutting)**: my B.Sc. thesis.
Reinforcement learning (PPO) versus mixed-integer linear programming (MILP) for cutting
steel coils under stochastic demand on a rolling horizon. In the most complex scenario,
the RL agent cut average daily cost by 73.8% and lost sales by 98.5% compared with MILP.
